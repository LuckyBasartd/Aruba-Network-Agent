Manually add hosts outside the scanner's configured subnets — out-of-band management interfaces, edge devices, partner equipment. Each host carries a monitoring mode that tells the agent how much access it has:

icmp
Ping every 30 s. No SNMP, no backup attempts, no ARP queries.
snmp_ro
SNMPv3 reachability + sysName lookups. Backups and ARP are skipped.
snmp_rw
Full access — SNMP for reachability, REST/SSH for backups.
auto
Let the agent decide (matches scanner-discovered hosts).
