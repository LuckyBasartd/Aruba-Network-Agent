Cisco IOS / IOS-XE

Used by NAPALM to talk to Cisco switches over SSH. Applies to every host the C3 vendor detector classifies as cisco_ios. If username and password are blank, the driver falls back to the default [credentials] block.

Required for tasks that need privileged exec mode on traditional IOS images. IOS-XE often doesn't need this.
When set, NAPALM uses SSH public-key auth instead of the password above. Install the matching public key on each Cisco switch (ip ssh pubkey-chain). For an unencrypted key, leave password blank; for an encrypted key, set password to its passphrase. File must be mode 600, owned by aruba-agent.
ios covers Catalyst / IOS-XE. iosxr for carrier-grade IOS-XR. nxos_ssh for Nexus / NX-OS.
Restart the agent to apply.
Notes
  • NAPALM uses SSH (netmiko) under the hood. The agent host's ~/.ssh/known_hosts isn't consulted — host-key checks are disabled to keep the polling path frictionless.
  • On first connect to a new switch, NAPALM may take 10-15 seconds while it negotiates SSH and learns the prompt. Subsequent calls reuse the same session for a single poll cycle.
  • Saved credentials take effect on the next agent restart.
