Arista EOS

Used by NAPALM to talk to Arista switches via eAPI (JSON-RPC over HTTPS). Applies to every host the C3 vendor detector classifies as arista_eos. If username and password are blank, the driver falls back to the default [credentials] block.

eAPI must be enabled on the switch: 
management api http-commands
   no shutdown
   protocol https
Required for tasks that need privileged exec mode. Most read-only tasks don't.
https recommended. http is lab-only — eAPI traffic includes credentials.
Leave blank unless your eAPI listens on a non-standard port.
Restart the agent to apply.
Notes
  • eAPI uses self-signed TLS by default. NAPALM doesn't verify the certificate, which keeps the polling path frictionless on a freshly-provisioned switch.
  • On EOS, ``copy running-config startup-config`` is the equivalent of Cisco's ``write memory`` — the backup task issues that automatically.
  • Saved credentials take effect on the next agent restart.
